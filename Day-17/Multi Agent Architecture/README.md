# Multi-Agent AI System using Azure OpenAI

## Project Description

This project demonstrates a Multi-Agent AI workflow built using Azure OpenAI.

The architecture follows the Supervisor Pattern where a central orchestrator coordinates specialized agents responsible for research, analysis, and response generation.

---

# Features

* Azure OpenAI Integration
* Multi-Agent Workflow
* Supervisor-Based Orchestration
* Shared State Management
* Modular Agent Design
* Enterprise Architecture Pattern

---

# Architecture

```text
                        User Query
                             │
                             ▼
                    Supervisor Agent
                             │
         ┌───────────────────┼───────────────────┐
         │                   │                   │
         ▼                   ▼                   ▼
  Research Agent      Analysis Agent      Writer Agent
         │                   │                   │
         └───────────────────┼───────────────────┘
                             ▼
                      Final Response
```

# Agent Overview

## Research Agent

Purpose:

* Gather information
* Extract key concepts
* Generate research notes

---

## Analysis Agent

Purpose:

* Analyze findings
* Compare alternatives
* Generate insights
* Perform reasoning

---

## Writer Agent

Purpose:

* Format content
* Improve readability
* Generate final response

---

## Supervisor Agent

Purpose:

* Coordinate all agents
* Manage workflow
* Return final output

# Supervisor Workflow

```python
def supervisor_agent(query):

    research = research_agent(query)

    analysis = analysis_agent(research)

    final_output = writer_agent(analysis)

    return final_output
```
